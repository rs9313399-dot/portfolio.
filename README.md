# Portfolio Static Site

This repository contains a single-page HTML portfolio for Ratnesh Singh. It presents an AI, IoT, machine learning, and full-stack development profile with polished metadata, custom styling, and a deployment-ready static structure.

## Highlights

- Single-file portfolio built with HTML, CSS, and JavaScript.
- SEO metadata, canonical URL, Open Graph tags, and social preview image support.
- Responsive layout for desktop and mobile screens.
- Sections for profile summary, skills, projects, and contact details.
- Custom cursor, scroll progress, animated sections, and modern dark visual design.
- Ready to deploy on Vercel, GitHub Pages, Netlify, or any static host.

## Project Structure

```text
portfolio./
├── index.html       # Complete portfolio page
├── og-image.png     # Social preview image
└── .gitignore
```

## Getting Started

Clone the project:

```bash
git clone https://github.com/rs9313399-dot/portfolio..git
cd portfolio.
```

Open `index.html` in a browser, or serve it locally:

```bash
python -m http.server 3000
```

Then visit `http://localhost:3000`.

## Customization

- Update profile text, project cards, and links in `index.html`.
- Replace `og-image.png` to change the social sharing preview.
- Update the canonical URL and Open Graph URL before deploying to a new domain.

## Deployment

Because this is a static site, it can be deployed without a build step. Upload the files to any static hosting platform or connect the repository to a static deployment provider.
